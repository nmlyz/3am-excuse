3am-excuse writes one line to a text file: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The line was picked from 36 candidates by pairwise judging against the brief — a refusal backed by the wallet's own memory of the owner's last 3 AM mistake, told in two concrete nouns and closed on its strongest beat. The wallet does not explain itself twice.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 99 characters, a single line, and ends on its strongest beat. The program builds the line from two clauses — the refusal at 3 AM, then the remembered receipt from the last time it signed at that hour — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
